The last test showed the main voltage regulation circuit was working on the v2 boards, but we hadn’t tried powering anything.

I took one of the old v1 boards and quarantined it’s non-working regulation circuit out. I then connected the HBPv2 PCB with the working regulator in, to power the rest of the v1 board. Here’s the frankenstein job:

HBP-v1-v2

We need to send the boards out for assembly to completely build a full board, which costs several thousand dollars, including component parts and the assembly labor itself. By using the v2 regulator circuit with the old v1 boards, we can verify that the regulator can power all the components without spending all that money.

I’m happy to say that our FPGA programmed successfully, so it looks like the HBPv2’s main voltage regulation circuit is fixed =). Photographic proof:

HBP-v1-v2 FPGA programming success
