I just finished part of my latest project and started messing around with the Atlys board that came last week from Digilent. It features a Spartan 6 FPGA (Xilinx), the latest low-cost FPGA on sale. With the academic discount, it’s only $200 ($350 otherwise).

As you can see, it’s a really small board, about the size of my hand. It even comes with a nice carrying case a bit larger than a VHS case.

It comes with some cool peripherals:

  • four HDMI ports (two in, two out)
  • USB-programmer (so a JTAG debugger isn’t necessary, but is supported)
  • USB HID devices (keyboard, mouse)
  • UART-over-USB (USB/Serial dongles and null RS232 cables are getting old)
  • Mic, Line in/out, and headphone out (“HP OUT”). Warning: headphone out is REALLY LOUD
  • The usual bank of switches, buttons, LEDs, and GPIOs

I’m not sure what I need two HDMI inputs for, but it seems that it could be used for something really cool.

I haven’t tried any of my own RTL, but Digilent has packaged some nice tools for interfacing with the board. You can emulate more switches and LEDs, program the flash or the FPGA directly, and run a whole slew of tests.

My favorite feature though is real-time power monitoring. It will even draw a rolling graph, showing the power consumption.

While running the power monitoring, I ran the demo bitstream and played with the buttons. This causes the FPGA to module a sine wave over the audio outputs and you can see the 1.2V (internal FPGA logic) go up! Flipping the switches turns on some of the board LEDs, and you can see the 3.3V IO current step up a bit too.

I haven’t verified it, but I think the power monitoring should still work when running my own RTL and not Digilent’s demo. I’m also curious to see how software running on a soft core affects power, and if it correlates with power consumption on hard-coded circuits (ASICs). It seems that an separate microcontroller is talking with the utility running on my computer, and is independent of the FPGA. Very cool!
